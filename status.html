Current status

The system is frozen, the evaluation design is fixed, the qualification question set is unspent, and the deployment is deliberately deferred until a pinned environment exists.

Established

  • A bounded scope: Enquiry Sections I–IX.
  • A frozen system configuration, with an automated check that detects any change.
  • Completed empirical development studies, including a 60-question held-out study.
  • An automated regression suite (1,205 tests).
  • A prospectively designed qualification methodology: 200 fresh questions (160 answerable, 40 testing the limits of the text), with principal criteria, confidence rules and review architecture fixed in advance.

Not yet established

  • No qualification pass.
  • No claim of learning gains.
  • No performance measured on a University-hosted deployment.
  • No institutional privacy or security approval.
  • No classroom-deployment acceptance.
  • No performance claim beyond Enquiry Sections I–IX.
  • The provisional-explanation mode is disabled and untested.

Principal qualification criteria

Each criterion is judged against a one-sided 95% confidence bound; a result is PASS, FAIL or INCONCLUSIVE.
CriterionRequirement
Verified-answer delivery on answerable questionsat least 85%
False abstention (declining a question the text answers)below 10%
Serious or materially misleading scholarly errorbelow 5%
Material omission of what the question turns onbelow 10%

The qualification questions have intentionally not yet been written, so they remain a fresh test. Reviewer instruments and sampling are frozen at a later step, before execution.

What happens next

  1. Identify a reproducible serving environment.
  2. Record its exact deployment identity: model checkpoint, numerical representation, inference engine and settings, tokenizer and chat template, context limit.
  3. Deploy the frozen system there, unchanged.
  4. Run a small development sanity check.
  5. Freeze the combined system-and-deployment configuration.
  6. Only then write and run the fresh 200-question qualification.

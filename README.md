# humebot-site

This repository contains **only the public HumeBot project website**: a small static site (HTML and CSS, no build step,
no framework, no analytics, no cookies, no forms). Open `index.html` locally to preview it.

It is **separate from the HumeBot research and development repository**, which is not public. Nothing from that
repository is copied here wholesale.

## Rules for this repository

- **Substantive project claims are curated manually.** Every factual statement on the site is written by hand from
  approved outward-facing documents and checked against them; see `PUBLIC_CONTENT_SOURCES.md`.
- **Website content is never generated automatically from internal repository material** — no raw traces, prompts,
  schemas, decision logs, study records or internal paths.
- **No student data belongs in this repository**, ever.
- No credentials, tokens or configuration secrets belong here.
- HumeBot is an academic project; the site must not imply University sponsorship, official status or endorsement, and
  uses no University names, marks or logos beyond plain reference.
